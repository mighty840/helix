## What is Helix?

Helix is a system for encoding executable algorithms as synthetic DNA sequences stored in aqueous or encapsulated form. Programs are compiled to an ACGT nucleotide string, persisted in DNA, retrieved via sequencing, and executed on a software virtual machine.

The goal: store fundamental algorithms — sorting, searching, arithmetic — in a physical medium with a 10,000-year shelf life, and retrieve them intact decades later.

## The Pipeline

```
.hx source
    │
    ▼ helix-asm  (parse + resolve + encode)
raw codons
    │
    ▼ helix-bio  (GC / homopolymer / repeat optimization)
bio-safe codons
    │
    ▼ helix-ecc  (SYNC + Reed-Solomon + TMR)
DNA string  ──────────────────────── aqueous / encapsulated storage
    │
    ▼ helix-ecc  (decode: TMR vote + RS correction + SYNC resync)
raw codons
    │
    ▼ helix-vm   (decode + execute)
result
```

## Why DNA?

| Medium | Density | Stability | Rewrite |
|--------|---------|-----------|---------|
| Flash (NAND) | ~1 TB/cm³ | 10 years | Yes |
| Magnetic tape | ~10 GB/cm³ | 30 years | Yes |
| Synthetic DNA | ~215 PB/gram | 10,000+ years | No |

DNA wins on density and longevity. Helix targets the niche where read-only, archival storage of compact deterministic programs is worth the synthesis cost.
