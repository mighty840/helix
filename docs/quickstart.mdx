## Prerequisites

- Rust 1.86+ (uses `is_multiple_of` stabilised in 1.86)
- Cargo

```bash
rustup update stable
```

## Clone and Build

```bash
git clone https://github.com/mighty840/helix.git
cd helix
cargo build --workspace -j4
```

## Run an Example

Assemble the Fibonacci program and execute it:

```bash
# Assemble fibonacci.hx → DNA string, then pipe to the VM
cargo run --bin helix-asm -- examples/fibonacci.hx --no-tmr 2>/dev/null \
  | cargo run --bin helix-vm --
# R1 = 55  (F(10))
```

## Write Your First Program

Create `hello.hx`:

```asm
.program "hello"
.version 1
.text
.entry main

main:
    IMML R1, 42      ; R1 = 42
    IMML R2, 8       ; R2 = 8
    ADD  R3, R1, R2  ; R3 = 50
    HALT
```

Assemble and run:

```bash
cargo run --bin helix-asm -- hello.hx --no-tmr 2>/dev/null \
  | cargo run --bin helix-vm --
# R3 = 50
```

## Simulate Storage Errors

See how the ECC layers survive a 0.5% substitution rate:

```bash
cargo run --bin helix-sim -- \
  "$(cargo run --bin helix-asm -- examples/gcd.hx --no-tmr 2>/dev/null)" \
  --sub-rate 0.005 --runs 50
```

## Run All Tests

```bash
cargo test --workspace -j4
# 159 tests, 0 failures
```
