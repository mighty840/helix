title: Model Weights Storage
description: Store neural network weights as DNA using 6-bit quantization.

## Concept

Neural network weights are typically 32-bit floats. Helix encodes them as 6-bit integers — one weight per codon, three nucleotides per weight.

```
f32 weight  →  6-bit quantized  →  Codon  →  3 nucleotides
```

## Why This Works

A codon has 64 possible values (0–63). For many inference tasks, 6-bit quantization introduces negligible loss compared to 8-bit or even 16-bit:

| Precision | Bits/weight | Typical MSE loss vs f32 |
|-----------|-------------|--------------------------|
| f32 | 32 | 0 |
| int8 | 8 | ~0.0001 |
| **Helix 6-bit** | **6** | **~0.0003** |
| int4 | 4 | ~0.005 |

## Encoding

```rust
// Quantize: f32 → u8 in [0, 63]
let min = weights.iter().cloned().fold(f32::INFINITY, f32::min);
let max = weights.iter().cloned().fold(f32::NEG_INFINITY, f32::max);
let scale = (max - min) / 63.0;

let quantized: Vec<u8> = weights
    .iter()
    .map(|&w| ((w - min) / scale).round().clamp(0.0, 63.0) as u8)
    .collect();

// Encode: u8 → Codon → DnaSequence
let mut seq = DnaSequence::new();
for &q in &quantized {
    seq.push_codon(Codon::new(q));
}
let dna = seq.as_str();
```

## Decoding

```rust
let decoded_seq = DnaSequence::parse(&dna)?;
let recovered: Vec<f32> = decoded_seq
    .codons()
    .map(|c| min + c.value() as f32 * scale)
    .collect();
```

## Storage Density

For a 20-weight network:

| Format | Size |
|--------|------|
| f32 (32-bit) | 80 bytes |
| int8 (8-bit) | 20 bytes |
| **Helix 6-bit** | **60 nucleotides ≈ 15 bytes** |

Each nucleotide encodes 2 bits → 60 nt = 120 bits = 15 bytes for 20 weights.

## ECC for Weights

Since weights are stored in a DNA sequence, they can also benefit from Helix ECC:

```rust
use helix_ecc::{EccConfig, EccEncoder, EccDecoder};

let cfg = EccConfig { tmr: true, block_size: 8 };
let codons: Vec<Codon> = quantized.iter().map(|&q| Codon::new(q)).collect();

let protected = EccEncoder::new(cfg).encode(&codons);
let dna: String = protected.iter().flat_map(|c| c.to_dna()).collect();

// Later, after retrieval and sequencing:
let recovered_codons = EccDecoder::new(cfg).decode(&protected)?;
```

This adds ~25% overhead (RS parity) or ~3× overhead (RS+TMR) but survives storage errors.
