## Arithmetic

### ADD — Add

```
ADD Rd, Rs1, Rs2
```

`Rd = (Rs1 + Rs2) & 0xFFFF`  
Wraps silently on overflow. Flags not affected.

### SUB — Subtract

```
SUB Rd, Rs1, Rs2
```

`Rd = (Rs1 − Rs2) & 0xFFFF`  
Wraps silently on underflow.

### MUL — Multiply

```
MUL Rd, Rs1, Rs2
```

`Rd = (Rs1 × Rs2) & 0xFFFF`  
Low 16 bits of the product.

### DIV — Divide

```
DIV Rd, Rs1, Rs2
```

`Rd = Rs1 / Rs2`  
Raises `DivZero` trap if Rs2 = 0.

### MOD — Modulo

```
MOD Rd, Rs1, Rs2
```

`Rd = Rs1 % Rs2`  
Raises `DivZero` trap if Rs2 = 0.

### INC / DEC

```
INC Rd, Rs    ; Rd = Rs + 1
DEC Rd, Rs    ; Rd = Rs - 1
```

## Logic

### AND / OR / XOR

```
AND Rd, Rs1, Rs2
OR  Rd, Rs1, Rs2
XOR Rd, Rs1, Rs2
```

Bitwise operations. Flags not affected.

### NOT

```
NOT Rd, Rs
```

`Rd = ~Rs`  
`NOT R1, R0` → R1 = 0xFFFF (since R0 = 0).

### SHL / SHR

```
SHL Rd, Rs1, Rs2    ; Rd = Rs1 << Rs2
SHR Rd, Rs1, Rs2    ; Rd = Rs1 >> Rs2
```

Logical shifts (zero-fill). Rs2 values ≥ 16 produce 0.

## Load Immediate

### IMML — Load Low Byte

```
IMML Rd, imm8
```

Sets `Rd[7:0] = imm8`. **High byte is unchanged.**

To load a 16-bit constant:
```asm
IMML R1, 0xAB   ; R1 = ????AB
IMMH R1, 0xCD   ; R1 = CDAB
```

### IMMH — Load High Byte

```
IMMH Rd, imm8
```

Sets `Rd[15:8] = imm8`. Low byte is unchanged.

## Memory

### LOAD

```
LOAD Rd, Rs
```

`Rd = mem[Rs]`  
Raises `MemFault` if Rs ≥ memory size.

### STORE

```
STORE Rd, Rs
```

`mem[Rd] = Rs`  
Raises `MemFault` if Rd ≥ memory size.

## Stack

The stack pointer grows downward. Initial SP = top of memory.

### PUSH

```
PUSH Rs
```

Decrements SP then stores Rs at the new SP.

### POP

```
POP Rd
```

Loads from SP into Rd, then increments SP.

## Comparison

### CMP

```
CMP Rs1, Rs2
```

Computes `Rs1 − Rs2`, sets flags, **discards result**.

| Flag | Condition |
|------|-----------|
| Zero | Rs1 == Rs2 |
| Negative | Rs1 < Rs2 (unsigned high bit of difference) |

## Branches

All branch offsets are **signed 8-bit** values encoded in codon 2.

```
new_pc = current_pc + offset
```

| Mnemonic | Condition |
|----------|-----------|
| JMP off | always |
| BEQ off | zero flag set |
| BNE off | zero flag clear |
| BLT off | negative flag set |
| BGE off | negative flag clear |

<Tip>
Use labels in `.hx` programs — the assembler calculates offsets. Manual offsets are only needed when building instruction arrays directly in Rust tests.
</Tip>

## Subroutines

### CALL

```
CALL off
```

Pushes `pc + 1` (return address) onto the stack, then jumps to `pc + offset`.

### RET

```
RET
```

Pops the return address from the stack and jumps to it.

## Special

### NOP

No operation. Opcode 0x1B. Used as padding in ECC blocks.

### HALT

Stops execution. The VM returns `Ok(())`.

### SYNC

ECC frame marker. The assembler never emits this — it is inserted by `helix-ecc`.

### ECCP

Reed-Solomon parity storage. Inserted by `helix-ecc`.

### TRAP

```
TRAP code
```

Raises a trap. Programs can use this for explicit error signalling.
