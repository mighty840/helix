## Register File

8 general-purpose registers, 16-bit unsigned integers.

| Register | Alias | Notes |
|----------|-------|-------|
| R0 | ZERO | Hardwired to 0. Writes are silently discarded. |
| R1 | GP1 | General purpose |
| R2 | GP2 | General purpose |
| R3 | GP3 | General purpose |
| R4 | GP4 | General purpose |
| R5 | GP5 | General purpose |
| R6 | GP6 | General purpose |
| R7 | ACC | Accumulator / conventional return-value register |

## Instruction Format

Every instruction is exactly **4 codons = 24 bits = 12 nucleotides**.

```
┌──────────┬──────────┬──────────┬──────────┐
│  Codon 1 │  Codon 2 │  Codon 3 │  Codon 4 │
│  OPCODE  │  DST     │  SRC1    │  SRC2    │
│  6 bits  │  6 bits  │  6 bits  │  6 bits  │
└──────────┴──────────┴──────────┴──────────┘
```

Fields are interpreted differently per opcode family:

| Format | Codon 2 | Codon 3 | Codon 4 |
|--------|---------|---------|---------|
| R3 (arithmetic) | DST | SRC1 | SRC2 |
| R2 (unary / cmp) | DST | SRC | — |
| R1 (push/pop) | REG | — | — |
| Imm (IMML/IMMH) | DST | imm[7:0] split across fields | |
| Branch | offset[7:0] | — | — |

## Opcode Table

| Opcode | Mnemonic | Operation |
|--------|----------|-----------|
| 0x00 | ADD | Rd = Rs1 + Rs2 (wraps u16) |
| 0x01 | SUB | Rd = Rs1 − Rs2 (wraps u16) |
| 0x02 | MUL | Rd = Rs1 × Rs2 |
| 0x03 | DIV | Rd = Rs1 ÷ Rs2 (trap on 0) |
| 0x04 | MOD | Rd = Rs1 mod Rs2 (trap on 0) |
| 0x05 | INC | Rd = Rs + 1 |
| 0x06 | DEC | Rd = Rs − 1 |
| 0x07 | AND | Rd = Rs1 & Rs2 |
| 0x08 | OR | Rd = Rs1 \| Rs2 |
| 0x09 | XOR | Rd = Rs1 ^ Rs2 |
| 0x0A | NOT | Rd = ~Rs |
| 0x0B | SHL | Rd = Rs1 << Rs2 |
| 0x0C | SHR | Rd = Rs1 >> Rs2 |
| 0x0D | CMP | flags = Rs1 − Rs2 (no writeback) |
| 0x0E | LOAD | Rd = mem[Rs] |
| 0x0F | STORE | mem[Rd] = Rs |
| 0x10 | PUSH | stack ← Rs; sp-- |
| 0x11 | POP | Rd ← stack; sp++ |
| 0x12 | IMML | Rd[7:0] = imm8 |
| 0x13 | IMMH | Rd[15:8] = imm8 |
| 0x14 | JMP | pc = pc + off − 1 |
| 0x15 | BEQ | if zero: pc = pc + off − 1 |
| 0x16 | BNE | if !zero: pc = pc + off − 1 |
| 0x17 | BLT | if negative: pc = pc + off − 1 |
| 0x18 | BGE | if !negative: pc = pc + off − 1 |
| 0x19 | CALL | push pc+1; pc = pc + off − 1 |
| 0x1A | RET | pc = pop |
| 0x1B | NOP | no-op |
| 0x1C | HALT | stop execution |
| 0x1D | SYNC | SYNC marker (ECC use only) |
| 0x1E | ECCP | Reed-Solomon parity codon |
| 0x1F | TRAP | raise trap code |

## Flags

Set by `CMP`:

| Flag | Set when |
|------|----------|
| Zero | result == 0 |
| Negative | result[15] == 1 |

Flags are consumed by conditional branches (`BEQ`, `BNE`, `BLT`, `BGE`).

## Branch Offset Formula

Branches and jumps use a **relative signed offset** encoded in codon 2.

```
new_pc = (current_pc + 1) + offset − 1
       = current_pc + offset
```

Offset of **+1** is a no-op (advances to the next instruction normally).  
Offset of **−1** is an infinite loop.

The assembler computes offsets from label differences automatically — you never write offsets by hand in `.hx` programs.

## Trap Codes

| Code | Name | Cause |
|------|------|-------|
| 0x01 | DivZero | `DIV` or `MOD` with Rs2 = 0 |
| 0x02 | StackOverflow | `PUSH` with full stack |
| 0x03 | StackUnderflow | `POP` with empty stack |
| 0x04 | InvalidOpcode | unknown opcode codon |
| 0x05 | MemFault | out-of-bounds memory access |
