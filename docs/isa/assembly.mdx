## File Structure

A `.hx` file has three sections:

```asm
; Header directives
.program "name"
.version 1

; Optional data section
.data
label: .words val1, val2, ...

; Code section
.text
.entry main

main:
    ; instructions
    HALT
```

## Directives

| Directive | Description |
|-----------|-------------|
| `.program "name"` | Program name (metadata) |
| `.version N` | Version number |
| `.memory N` | Reserve N words of RAM |
| `.data` | Begin data section |
| `.text` | Begin code section |
| `.entry label` | Designate entry point |
| `.words v1, v2, ...` | Emit 16-bit word literals |

## Labels

Labels end with `:` and can be placed on their own line or before any instruction. Branches and calls reference labels by name — the assembler resolves the signed offset automatically.

```asm
loop:
    CMP  R1, R2
    BGE  done        ; assembler computes offset to 'done'
    ADD  R1, R1, R0
    JMP  loop
done:
    HALT
```

## Comments

Line comments start with `;`. No block comments.

```asm
; This is a comment
IMML R1, 42    ; inline comment
```

## Mnemonics

All mnemonics are case-insensitive. Registers are `R0`–`R7`.

```asm
IMML r1, 0xFF    ; lowercase ok
add R3, R1, R2   ; lowercase ok
```

## Immediates

Immediates can be decimal or hex (`0x` prefix):

```asm
IMML R1, 255      ; decimal
IMML R1, 0xFF     ; same value
```

Range: 0–255 (8-bit unsigned) for `IMML`/`IMMH`.

## Data Section

`.words` emits 16-bit values into the data segment, loaded at address 0 before execution.

```asm
.data
arr:  .words 10, 20, 30, 40, 50
size: .words 5

.text
.entry main

main:
    IMML R1, 0      ; base address
    LOAD R2, R1     ; R2 = arr[0] = 10
```

## Calling Convention (by convention, not enforced)

- Arguments: R1, R2, ... (caller sets)
- Return value: R7 (callee sets)
- Caller-saved: all registers
- Stack frame: caller-managed via PUSH/POP

```asm
; Call a subroutine
IMML R1, 48
IMML R2, 18
CALL gcd       ; jumps to gcd label, pushes return address

; Subroutine
gcd:
    CMP  R1, R2
    BEQ  done
    ; ...
    RET
done:
    ADD  R7, R1, R0    ; return R1 in R7
    RET
```

## Full Example: Fibonacci

```asm
.program "fibonacci"
.version 1
.text
.entry main

main:
    IMML R1, 0       ; a = 0
    IMML R2, 1       ; b = 1
    IMML R3, 0       ; i = 0
    IMML R4, 10      ; n = 10

loop:
    CMP  R3, R4
    BGE  done
    ADD  R5, R1, R2  ; t = a + b
    ADD  R1, R2, R0  ; a = b
    ADD  R2, R5, R0  ; b = t
    INC  R3, R3      ; i++
    JMP  loop

done:
    HALT
; R1 = F(10) = 55
```
