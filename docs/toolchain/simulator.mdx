## Overview

`helix-sim` injects controlled errors into a DNA string and measures how well the ECC stack recovers the original program. Use it to:

- Tune error rates for your storage medium
- Compare RS-only vs RS+TMR configurations
- Validate that ECC parameters are sufficient for your target environment

## Quick Start

```rust
use helix_sim::{inject::InjectionConfig, metrics::simulate};
use helix_ecc::EccConfig;

let cfg = EccConfig { tmr: false, block_size: 8 };

let report = simulate(
    &dna_string,
    &original_instructions,
    InjectionConfig::composite(
        0.005,  // 0.5% substitution rate
        0.001,  // 0.1% insertion rate
        0.001,  // 0.1% deletion rate
        42,     // RNG seed (same seed = deterministic)
    ),
    cfg,
);

report.print_summary();
println!("Recovery rate: {:.1}%", report.recovery_rate() * 100.0);
```

## Injection Modes

### Composite (Independent Errors)

```rust
InjectionConfig::composite(sub_rate, ins_rate, del_rate, seed)
```

Each nucleotide independently has a `sub_rate` chance of substitution, `ins_rate` chance of insertion, and `del_rate` chance of deletion.

### Burst Mode

```rust
InjectionConfig::burst(burst_prob, within_burst_rate, seed)
```

Errors cluster in bursts — a random position starts a burst with probability `burst_prob`, and within a burst each subsequent base has `within_burst_rate` probability of additional error. Models enzymatic degradation and strand breaks.

## SimulationReport

```rust
pub struct SimulationReport {
    pub injection: InjectionStats,    // how many errors were injected
    pub ecc_success: bool,            // did ECC decode succeed?
    pub instruction_matches: usize,   // how many instructions recovered correctly
    pub total_instructions: usize,    // original instruction count
}

impl SimulationReport {
    pub fn recovery_rate(&self) -> f32 { ... }   // 0.0–1.0
    pub fn print_summary(&self) { ... }
}

pub struct InjectionStats {
    pub substitutions: usize,
    pub insertions: usize,
    pub deletions: usize,
}

impl InjectionStats {
    pub fn total_errors(&self) -> usize { ... }
}
```

## Determinism

The same `seed` always produces the same injection pattern:

```rust
let r1 = simulate(&dna, &instrs, InjectionConfig::composite(0.001, 0.0, 0.0, 777), cfg);
let r2 = simulate(&dna, &instrs, InjectionConfig::composite(0.001, 0.0, 0.0, 777), cfg);
assert_eq!(r1.injection.substitutions, r2.injection.substitutions);
```

## Interpreting Results

| Recovery rate | Interpretation |
|---------------|----------------|
| 1.0 | Perfect recovery — all instructions match original |
| 0.9–1.0 | Good — ECC corrected most errors |
| 0.5–0.9 | Partial — some blocks uncorrectable; consider TMR |
| \< 0.5 | Poor — error rate exceeds ECC capacity for this config |

## Choosing Parameters

Typical starting points:

| Storage scenario | Substitution rate | TMR? |
|-----------------|-------------------|------|
| Short-term lab storage | 0.001–0.002 | No |
| 10-year encapsulated | 0.003–0.005 | No |
| 50+ year archival | 0.005–0.01 | Yes |
| Nanopore sequencing | 0.01–0.05 | Yes |
