## Overview

`helix-vm` implements the fetch-decode-execute loop for the Helix ISA. It takes a slice of decoded instruction arrays and runs them to completion (HALT) or until a trap.

## CPU State

```rust
pub struct Cpu {
    pub regs: [u16; 8],    // R0–R7 (R0 always reads as 0)
    pub pc: usize,          // program counter (instruction index)
    pub flags: Flags,       // zero, negative
    // (stack pointer is internal to Memory)
}

pub struct Flags {
    pub zero: bool,
    pub negative: bool,
}
```

## Running a Program

```rust
use helix_vm::{Cpu, Memory};

let mut cpu = Cpu::new(Memory::new());
let result = cpu.run(&instructions);

match result {
    Ok(()) => println!("R1 = {}", cpu.regs[1]),
    Err(CpuError::Trap(TrapCode::DivZero)) => eprintln!("division by zero"),
    Err(e) => eprintln!("error: {e}"),
}
```

`instructions` is `&[[Codon; 4]]` — a slice of 4-codon instruction arrays.

## Memory

Default memory is 256 16-bit words (512 bytes). The stack starts at the top and grows downward.

```rust
pub struct Memory {
    pub data: [u16; 256],
    pub sp: usize,          // stack pointer (word index)
}

impl Memory {
    pub fn new() -> Self { ... }
    pub fn load_data(&mut self, words: &[u16]) { ... }  // loads at addr 0
    pub fn read(&self, addr: u16) -> Result<u16, CpuError> { ... }
    pub fn write(&mut self, addr: u16, val: u16) -> Result<(), CpuError> { ... }
    pub fn push(&mut self, val: u16) -> Result<(), CpuError> { ... }
    pub fn pop(&mut self) -> Result<u16, CpuError> { ... }
}
```

## ProgramLoader

`ProgramLoader` handles the ECC decode step, turning a DNA string or raw codon slice into an executable instruction array.

```rust
use helix_vm::ProgramLoader;
use helix_ecc::EccConfig;

// From raw codons (no ECC decode)
let prog = ProgramLoader::from_raw_codons(&codons)?;

// From DNA string (full ECC decode)
let prog = ProgramLoader::new(cfg).from_dna_string(&dna)?;

pub struct LoadedProgram {
    pub instructions: Vec<[Codon; 4]>,
}
```

## Error Types

```rust
pub enum CpuError {
    Trap(TrapCode),
    Ecc(EccError),
}

pub enum TrapCode {
    DivZero,
    StackOverflow,
    StackUnderflow,
    InvalidOpcode,
    MemFault,
}
```

## R0 Invariant

R0 is hardwired to zero. The CPU silently ignores writes to R0 — you can use `ADD Rd, Rs, R0` as a move instruction:

```asm
ADD R3, R1, R0    ; R3 = R1 + 0 = R1  (move)
```

## Execution Loop

The CPU executes until:
1. `HALT` instruction — returns `Ok(())`
2. A trap condition — returns `Err(CpuError::Trap(...))`
3. No `HALT` but all instructions consumed — returns `Ok(())` (past-end halt)
