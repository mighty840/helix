What is Helix?

§ 1.0 — Introduction

Helix is a system for encoding executable algorithms as synthetic DNA sequences stored in aqueous or encapsulated form. Programs are compiled to an ACGT nucleotide string, persisted in DNA, retrieved via sequencing, and executed on a software virtual machine.

The goal: store fundamental algorithms — sorting, searching, arithmetic — in a physical medium with a 10,000-year shelf life, and retrieve them intact decades later.

DNA density:
215 PB/gram
vs Flash:
~1 TB/cm³
Helix is not biological computation. It uses DNA as a storage medium — the same way you'd use tape or flash — but with far superior density and longevity.

Your First Program

§ 1.2 — Assembly Language

Write a .hx file, assemble to a DNA string, execute on the VM:

assembles to
~252 nt
(21 instrs ×
12 nt/instr)
+ ECC overhead
fibonacci.hx 
.program "fibonacci"
.version 1
.text
.entry main

main:
  IMML R1, 0      ; a = 0
  IMML R2, 1      ; b = 1
  IMML R3, 0      ; i = 0
  IMML R4, 10     ; n = 10

loop:
  CMP  R3, R4
  BGE  done       ; i ≥ 10 → stop
  ADD  R5, R1, R2 ; t = a + b
  ADD  R1, R2, R0 ; a = b  (R0 = 0)
  ADD  R2, R5, R0 ; b = t
  INC  R3, R3     ; i++
  JMP  loop

done:
  HALT
; → R1 = 55  (F(10))
